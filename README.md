# CustomNamePings — Настоящие упоминания по имени в Vencord

Полноценный плагин для **Vencord** / **Vesktop**, который превращает упоминания вашего реального имени или ников в настоящие пинги Discord.

## Особенности

- 🔴 **Настоящие красные бейджи**: на канале и сервере появляется красный значок непрочитанного упоминания (как при реальном `@упоминании`).
- 🔔 **Звук пинга**: воспроизводится аутентичный звук входящего упоминания Discord.
- 💬 **Подсветка сообщений**: строка сообщения с вашим именем подсвечивается характерным желтоватым фоном.
- 🖥️ **Системные уведомления**: всплывающее уведомление на рабочем столе с текстом сообщения и автором.
- 🧠 **Умная морфология и падежи**: автоматически распознаёт уменьшительно-ласкательные формы и склонения по падежам (*Саня ↔ Санёк ↔ Санечка, Саша ↔ Сашка, Александр ↔ Саша* и любые другие).
- 🔤 **Нечёткий поиск (Fuzzy match)**: распознаёт растягивание букв (*Саааня*, *Ефросиммм*) и опечатки, при этом игнорирует похожие русские слова (*шуткой, сушкой* и др.) и чужие имена (*Алексей, Даня, Ваня*).
- 🛡️ **Фильтрация**:
  - Вайтлист / блеклист серверов.
  - Блеклист каналов и целых категорий (с удобным добавлением прямо через правый клик по каналу / категории в Discord).

## Установка

### Для тех, кто собирает Vencord из исходников (или Vesktop)

1. Откройте терминал в корневой папке вашего репозитория Vencord:
```bash
git clone https://github.com/efrosim/CustomNamePings src/userplugins/CustomNamePings
```

2. Соберите проект:
```bash
pnpm build
```

3. Перезапустите Discord (`Ctrl + R`).

4. Зайдите в **Настройки ➔ Vencord ➔ Плагины** и настройте свои имена и параметры в **CustomNamePings**.
